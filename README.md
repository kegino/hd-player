# HD Player (hdplayer.store)

Site oficial do **HD Player** — O melhor aplicativo e reprodutor de IPTV em 4K e Full HD.

- **Domínio oficial:** [https://hdplayer.store](https://hdplayer.store)
- **Palavra-chave foco:** `HD player`
- **Stack:** TanStack Start + React 19 + Nitro (node-server) + Tailwind CSS v4 + TypeScript
- **Suporte:** WhatsApp oficial `+55 (11) 93382-1957`

## Scripts disponíveis

```bash
pnpm install
pnpm dev       # Inicia servidor de desenvolvimento local
pnpm build     # Gera build de produção (.output)
pnpm preview   # Pré-visualiza o build localmente
```

## Docker

O repositório inclui Dockerfile multi-stage com `node:20-alpine` e `pnpm` para deploy no EasyPanel ou qualquer servidor containerizado.
